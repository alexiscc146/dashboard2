Before this works you need to complete two one-time setup steps:
Step A — Host this file at an https:// URL (GitHub Pages is free, ~5 min). See instructions below.
Step B — Register an Azure AD app to get a Client ID (~10 min). See instructions below.

① Host on GitHub Pages (one-time · ~5 min)

  1. Go to github.com and sign in (or create a free account).
  2. Click + → New repository. Name it anything (e.g. orakl-dashboard). Set it to Public. Click Create repository.
  3. On the repo page click uploading an existing file, drag in Orakl_PDO_Dashboard.html, commit.
  4. Rename the file to index.html (click the file → pencil icon → change name at top → commit).
  5. Go to Settings → Pages. Under "Branch" select main and click Save.
  6. After ~1 min your dashboard is live at https://YOUR-USERNAME.github.io/orakl-dashboard/. Copy that URL — you'll need it in Step B.

② Register an Azure AD app (one-time · ~10 min · ask IT if needed)

  1. Go to portal.azure.com and sign in with your Orakl Microsoft account.
  2. Search for App registrations in the top search bar → click it → + New registration.
  3. Name: anything (e.g. Orakl Dashboard). Supported account types: Accounts in this organizational directory only. Click Register.
  4. Copy the Application (client) ID shown on the overview page — paste it below.
  5. In the left sidebar click Authentication → + Add a platform → Single-page application.
  6. In "Redirect URIs" paste your GitHub Pages URL (e.g. https://YOUR-USERNAME.github.io/orakl-dashboard/). Click Configure.
  7. Still in Authentication, scroll to Implicit grant — check Access tokens and ID tokens. Click Save.
  8. In the left sidebar click API permissions → + Add a permission → Microsoft Graph → Delegated → search and add Files.Read and Sites.Read.All. Click Grant admin consent.

③ Azure AD credentials

Paste the Client ID from Step B above. Tenant ID is optional — leave blank unless IT specifies one.
